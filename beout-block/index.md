# BeOut Block

App iOS (SwiftUI) que ayuda a reducir el tiempo de pantalla: bloquea o limita apps con Screen Time (FamilyControls + DeviceActivity), pide resolver desafíos para desbloquear antes de tiempo y lleva una racha de días estilo GitHub.

Repo: [Be-Out/beout-swift-app](https://github.com/Be-Out/beout-swift-app). Local: `BEOUT_BLOCK` (default `../beout-block`).

* [Arquitectura](arquitectura.md) - Capas Clean + MVVM, managers Core, targets Xcode y requisitos de build.
* [Dominio y backend](dominio-backend.md) - Entidades, repositorios y tablas Supabase.
* [Pantallas](pantallas.md) - Auth, Home, Perfil y navegación.
* [Bloqueo y desafíos](bloqueo-desafios.md) - FamilyControls, extensión DeviceActivity, desafíos y monetización.
