# Stack

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **GSAP + ScrollTrigger** — reveals y sección “Cómo funciona” pineada
- **Lenis** — smooth scroll sincronizado con GSAP (`src/components/SmoothScroll.tsx`)
- **Motion** (ex Framer Motion) — micro-interacciones
- **shadcn/ui** sobre `@base-ui/react`
- **Supabase** (`@supabase/supabase-js`) — lista de espera
- **OpenNext** (`@opennextjs/cloudflare` + `wrangler`) — deploy en Cloudflare Workers

Fuente: `package.json` y `README.md` de `Be-Out/beout`.
