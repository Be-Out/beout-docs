# BeOut Move

App iOS de pasos, rachas y recorridos. Hermana de BeOut Block: misma identidad visual y patrones de código. Usa HealthKit para leer pasos, distancia y calorías; Supabase para auth, sync y amigos; y tiene widget y app de Apple Watch.

Repo: [Be-Out/beout-move-swift-app](https://github.com/Be-Out/beout-move-swift-app). Local: `BEOUT_MOVE` (default `../beout-move-swift-app`).
